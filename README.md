# Ancient Chaos / 混乱的先古

Steam Workshop: https://steamcommunity.com/sharedfiles/filedetails/?id=3790397889

Randomizes which Ancient appears in each act and creates a deterministic shuffled mapping for every `Ancient`-rarity relic. Every Ancient gift option displays—and grants—the shuffled relic.

The mapping is derived from the run seed, so it stays consistent through saving/loading and for multiplayer players who have the same mod version.
